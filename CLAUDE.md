## Key Concepts & Methodologies

### 16 Psychological Triggers (from documentation)

1. **Curiosity Gap** - Creating information gaps that demand closure
2. **Social Proof** - Leveraging crowd behavior and testimonials
3. **Authority** - Establishing credibility and expertise
4. **Scarcity** - Limited availability or exclusivity
5. **Reciprocity** - Give value first to receive engagement
6. **Storytelling** - Narrative arc with emotional resonance
7. **Pattern Interruption** - Breaking expected sequences
8. **Loss Aversion** - Fear of missing out (FOMO)
9. **Novelty** - Fresh perspectives and unique insights
10. **Controversy** - Challenging common beliefs
11. **Identity** - Alignment with viewer's self-image
12. **Progress** - Showing transformation journey
13. **Transformation** - Before/after narratives
14. **Mystery** - Maintaining suspense and revelation
15. **Urgency** - Time-sensitive calls to action
16. **Tribal Belonging** - Community and shared values

### Viral Strategy Tiers (from documentation)

- **Gold Tier**: 1M+ views, 10%+ engagement, 60%+ retention
- **Silver Tier**: 500K+ views, 7%+ engagement, 50%+ retention
- **Bronze Tier**: 100K+ views, 5%+ engagement, 40%+ retention

### Quality Thresholds (from documentation)

- Research Accuracy: ≥ 8.0/10
- Viral Potential: ≥ 9.0/10
- Script Quality: ≥ 9.0/10
- Production Feasibility: ≥ 8.0/10
- Overall Score: ≥ 9.0/10

## API Integration Guidelines

### Anthropic Claude
```python
# Primary use: Script generation, research synthesis
# Model: claude-sonnet-4 (current best)
# Fallback: claude-haiku (fast, simple tasks)

from anthropic import Anthropic
client = Anthropic(api_key="...")
response = client.messages.create(
    model="claude-sonnet-4-20250929",
    max_tokens=4096,
    messages=[{"role": "user", "content": "..."}]
)
```

### OpenAI
```python
# Primary use: Embeddings, alternative generation
# Embedding model: text-embedding-3-large
# Generation: gpt-4 or gpt-4-turbo

from openai import OpenAI
client = OpenAI(api_key="...")
embedding = client.embeddings.create(
    model="text-embedding-3-large",
    input="text to embed"
)
```
